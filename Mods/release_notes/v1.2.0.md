## BACKGROUND - BEFORE YOU DOWNLOAD!

This is my first ever post on F95. I've been an admirer from afar of this community, but after working on this project I wanted to give back to the community that has given so much to me!

I've been a long-time fan of Town of Magic and have played it a few times over with each new update, but I found myself wanting a little more in some cases: things that feel more alive and interactive, some QoL changes and, ultimately, just more porn lol. So I ended up tinkering around with the game and making my first mod.

It started with the H-Scene/Groping Loop mod. After playing around with it and getting it to work, I got used to it and even found it fun to see my idea come to life and play out how I wanted it to... then that idea spread to the rest of the game as I played through it again, adding more and more mods.

As of writing, there are currently 7 mods + the Mod Manager. I plan to add many more as I continue to play the game and ideas come to me.

**Claude was used in the making of this!**

This modpack has been extensively stress tested and I'm happy to say it works incredibly well.

With all of that said, thank you all for what you've given me. It's time to start giving back to you. 💖

## Apex's Modpack and Mod Manager v1.2.0
**Made for Town of Magic 0.77.002**

### Downloads (under *Assets*)
| File | What's inside |
|---|---|
| **Apex_Modpack_v1.2.0.zip** | All 7 mods, the Mod Manager, and the `mods` folder (templates + Modding Guide). Small. |
| **Apex_HD_Pack_v1.2.0.zip** | The HD pictures (add-on, needs the modpack). |
| **Apex_Modpack_v1.2.0_with_HD.zip** | Both in one download (only when it fits GitHub's size limit). |

### Install
1. Download **Apex_Modpack** (and the **HD Pack** if you want HD pictures).
2. Drag the `game` and `mods` folders from the zip into your Town of Magic folder (the one with `TownOfMagic.exe`) and choose merge / replace. Same for the HD Pack's `game` folder.
3. Start the game; **Apex's Modpack Manager** is at the top of the main menu.

**Updating from v1.1.0:** just install over it. The old single `Apex_Modpack.rpa` is replaced; the HD pictures now come from `Apex_HD.rpa`.
**Uninstall:** delete `game\Apex_Modpack.rpa`, `game\Apex_HD.rpa` and `game\apex_mods_loader.rpe.py` (the `mods` folder can stay). Saves keep working either way.
