## BACKGROUND - BEFORE YOU DOWNLOAD!

This is my first ever post on F95. I've been an admirer from afar of this community, but after working on this project I wanted to give back to the community that has given so much to me!

I've been a long-time fan of Town of Magic and have played it a few times over with each new update, but I found myself wanting a little more in some cases: things that feel more alive and interactive, some QoL changes and, ultimately, just more porn lol. ## Apex's Modpack and Mod Manager v1.6.1
**Made for Town of Magic 0.77.002**

### Downloads (under *Assets*)
| File | What's inside |
|---|---|
| **Apex_Modpack_v1.6.1.zip** | All 15 mods, the Mod Manager, and the `mods` folder (templates + Modding Guide). Small. |
| **HD Pack** | Unchanged in 1.6.1: use the three parts from the [v1.5.2 release](https://github.com/Apex-AIO/Apex-Town-of-Magic-Modpack/releases/tag/v1.5.2) (add-on, needs the modpack). |

### Install
1. Download **Apex_Modpack** (and the **HD Pack** from the v1.5.2 release if you want HD pictures).
2. Drag the `game` and `mods` folders from the zip into your Town of Magic folder (the one with `TownOfMagic.exe`) and choose merge / replace. Same for the `game` folder of **each** HD Pack part.
3. Start the game; **Apex's Modpack Manager** is at the top of the main menu.

**Updating from an older version:** just install over it. Saves keep working. Mods you switched off stay off; the new standalone mods (Combat Helpers, Movable Inventory Items, Inventory Backups) start on.
**Uninstall:** delete `game\Apex_Modpack.rpa`, `game\Apex_HD*.rpa` and `game\apex_mods_loader.rpe.py` (the `mods` folder can stay). Saves keep working either way.

### What's new in 1.6.1
- 👗 **Custom clothing uses the game's own fields** (thanks to afdkjhufm55 for the idea, issue #1): `apex_add_clothing` now also takes `equip_area`, `block_area`, `order`, `properties`, `stripable`, `molestable` and `extra`, so a piece can be worn on several areas (for example `["top|0", "sleeves|1"]`) and block others. The simple `area=` still works
- 🐛 Mistyped areas are explained in the Mod Manager instead of breaking the game
