## Apex's Modpack and Mod Manager v1.3.0
**Made for Town of Magic 0.77.002**

### Downloads (under *Assets*)
| File | What's inside |
|---|---|
| **Apex_Modpack_v1.3.0.zip** | All 9 mods, the Mod Manager, and the `mods` folder (templates + Modding Guide). Small. |
| **Apex_HD_Pack_v1.3.0_part1of2.zip** + **part2of2.zip** | The HD pictures (add-on, needs the modpack). Download and install **both** parts. |

### Install
1. Download **Apex_Modpack** (and the **HD Pack** if you want HD pictures).
2. Drag the `game` and `mods` folders from the zip into your Town of Magic folder (the one with `TownOfMagic.exe`) and choose merge / replace. Same for the `game` folder of **each** HD Pack part.
3. Start the game; **Apex's Modpack Manager** is at the top of the main menu.

**Updating from v1.2.0 or older:** just install over it. Saves keep working. The HD pack is now split in two parts (it grew past GitHub's 2 GB limit per file).
**Uninstall:** delete `game\Apex_Modpack.rpa`, `game\Apex_HD*.rpa` and `game\apex_mods_loader.rpe.py` (the `mods` folder can stay). Saves keep working either way.
