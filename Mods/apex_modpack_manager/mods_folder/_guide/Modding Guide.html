Modding Guide

Make your own mods for Town of Magic - no programming experience needed for the simple ones. Your mods go in the mods folder; the Mod Manager finds them, switches them on or off, and explains any problem in plain words.

Install someone's mod

  1. Open your Town of Magic folder (the one with TownOfMagic.exe). Next to the game folder is a mods folder.
  2. Put the mod's folder inside mods (one folder per mod).
  3. Start the game. The mod is listed under Apex's Modpack Manager → Your Mods, switched on.

To remove a mod, switch it off in the manager or delete its folder. Your saves keep working.

Your first mod in 2 minutes

  1. Main menu → Apex's Modpack Manager → Mod Tools.
  2. Type a name, pick Hello World, press Create mod. Its folder opens.
  3. Open script.rpy in any text editor (Notepad works; VS Code is nicer). Change the message.
  4. Restart the game and load a save - your message appears.
Every template has a READ ME.txt that explains it line by line.

What a mod folder looks like

Settings the player can change

Each setting = line adds a row to your mod's gear in the Mod Manager:

In your script: apex_setting("chance", 5) gives the player's choice (or the default). Changes apply after a restart.

Replace a game picture (no code)

Put a picture in your mod with the same path and name as a game picture - the game uses yours instead.

game:     images/CHAR/celica/celica_top_normal-530-530-1.png
your mod: mods/My Mod/images/CHAR/celica/celica_top_normal-530-530-1.png
Keep the same size. Names end in -WIDTH-HEIGHT-FRAMES: -530-530-6 is an animation with 6 frames side by side (3180 x 530 pixels). Mod Tools → Check my mods warns about wrong sizes.

Get the originals: Mod Tools → Export game pictures, type part of a name (e.g. celica_top_normal). They are copied to mods/_exported with the right folders and names.

Every pose is its own picture: celica_top_normal = standing, celica_squat_top_normal = squatting, and so on.

Add an accessory with stats

init python:
    apex_add_accessory("lucky_charm", "Lucky Charm", icon="charm.png",
                       description="A small charm that brings luck.",
                       stats={"luck": 10, "speed": 5}, regen=0)

It's given to the player once per save; Celica wears it from Equip → Appearance. Stats use the 0-100 scale the game shows: allure, lewdness, willpower, cooldown, arcane, speed, luck (minus numbers lower them). regen = HP and MP back per battle turn, in %.

Make custom clothing

init python:
    apex_add_clothing("red_top", "Red Top", area="top", picture="redtop",
                      icon="icon_redtop.png", description="A bright red top.",
                      stats={"allure": 5})

Exact version (the game's own fields): equip_area=["top|0", "sleeves|1"] is where it is worn (the first entry is the main area), block_area=["top|1"] is what it covers so nothing else fits there. Areas are top, bottom, feet, head, sleeves, each with a layer |0 (inner) or |1 (outer). Optional: order, properties, stripable, molestable, extra={...}.

The game draws each piece of clothing as its own picture on top of Celica, one picture per pose:

areaword in the picture namestanding picture
top, bratopimages/CHAR/celica/celica_top_<picture>-530-530-1.png
bottom, pantiesbottomimages/CHAR/celica/celica_bottom_<picture>-530-530-1.png
shoesfeetimages/CHAR/celica/celica_feet_<picture>-530-530-1.png

<picture> is your picture= word (redtop above). Other poses: <pose>_top_redtop-<size>.png, e.g. celica_squat_top_redtop-530-530-1.png. Poses without your picture show Celica without that piece - nothing breaks.

Fastest way to cover every pose: export _top_normal (the normal top in every pose, right names and sizes), recolor or redraw them, and rename normal to your word.

Add a morning scene

init python:
    apex_wakeup_scene("my_scene", chance=0.2)      # 1 in 5 quiet mornings

label my_scene:
    "Celica stretches as the morning sun warms the room."
    celica "Today feels like a good day."
    $ apex_give_gold(10)
    return

A label is a scene. Lines in quotes are the narrator; celica "..." is Celica speaking; $ runs one line of Python; return ends the scene. Indent with 4 spaces.

Your mod's name is found automatically from its folder - you never type it. Advanced modders can use anything Ren'Py and the game offer; the kit is just the safe, simple layer.

When something goes wrong

An error while playing: the game keeps running, your mod is switched off, and you get a message. Your Mods → (i) shows where it happened and what to do, in plain words. The full report is ERROR REPORT.txt in your mod folder.

The game crashed while starting (usually a typo in a script): restart once - the Mod Manager finds the mod that caused it, switches it off and explains the error.

Check my mods (Mod Tools) looks for missing files, wrongly sized pictures, clashes between mods and version mismatches.

After fixing, switch the mod back on and restart.
